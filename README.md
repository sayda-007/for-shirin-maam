
# For Shirin Ma'am — A Little Surprise

A small, personal appreciation website made by Sayda and Nobin for their professor, Shirin Ma'am.

The experience is a single-page journey: a welcome with Shirin Ma'am's portrait, seven automatically typed searches, a short personal note, two letters plus a shared note, and a quiet closing message.

There is no backend, no tracking, and no external media. The only photograph is the supplied portrait in `public/assets/shirin_maam.png`; all other artwork is local SVG or CSS.

## Development

```bat
npm install
npm run dev
```

## Quality checks

```bat
npm run lint
npm run build
```

All editable copy lives in `src/data/content.js`.
